# Подготовка к защите

Эта памятка относится к сделанному проекту. Преподаватель не прислал в сообщении отдельный список теоретических вопросов, поэтому здесь разобраны основные приёмы страницы.

## Что за что отвечает

HTML задаёт содержание: заголовки, абзацы, ссылки, списки и смысловые блоки. CSS определяет внешний вид и размещение. JavaScript нужен для программного поведения; здесь для статической страницы он не используется.

`header` — шапка, `nav` — навигация, `main` — основное содержание, `section` — тематический раздел с заголовком, `aside` — сопутствующий список курсов, `footer` — подвал. `h1` обозначает заголовок всей страницы, `h2` — заголовки разделов. `ul` — ненумерованный список, `ol` — упорядоченный, `li` — его пункт.

## Как работают стили

`class="site-nav"` связывает элемент с CSS-селектором `.site-nav`. Селектор `.site-nav a` выбирает ссылки внутри меню. `id="courses"` задаёт уникальный идентификатор, к которому ведёт ссылка `href="#courses"`.

Правила CSS могут переопределять друг друга: учитываются происхождение правила, важность, специфичность и порядок. Например, правило внутри мобильного медиазапроса меняет размер `h1`, когда ширина окна не превышает 725 px.

`margin` — внешний отступ, `padding` — внутренний, `border` — рамка. `box-sizing: border-box` включает рамки и внутренние отступы в заданную ширину элемента.

`--accent` — CSS-переменная. Значение используется через `var(--accent)`, поэтому основной цвет можно заменить в одном месте.

## Сетка и адаптивность

`.page-layout` использует Grid. Три колонки `5fr 3fr 2fr` делят доступную ширину в пропорции 50%, 30% и 20%. `minmax(0, ...)` позволяет колонке сжиматься, не удерживая минимальную ширину по содержимому.

`grid-template-areas` задаёт положение именованных областей. У каждого блока есть своё `grid-area`. При ширине до 950 px области перестраиваются в две колонки, до 725 px — в одну.

Меню использует Flexbox: на большом экране направление `column`, на телефоне — `row`. `flex-wrap: wrap` разрешает перенос пунктов.

Медиазапрос `@media (max-width: 725px)` действует при ширине окна до 725 CSS-пикселей включительно. На таком экране действуют и правила для 950 px; более поздние мобильные правила переопределяют нужные свойства.

Мета-тег `viewport` сообщает мобильному браузеру, что ширина страницы должна соответствовать ширине устройства. Без него браузер может показывать уменьшенную настольную страницу.

## Шрифты и единицы

`@font-face` подключает шрифт из файла. `font-display: swap` позволяет сначала показать запасной шрифт, пока основной загружается. `Georgia, serif` — запасные варианты.

`px` — CSS-пиксели, `em` зависит от размера шрифта, `vw` — процент ширины окна, `fr` — доля свободного места в Grid. `clamp(30px, 6vw, 44px)` плавно изменяет заголовок, ограничивая его размер снизу и сверху.

## Ссылки и доступность

`:hover` действует при наведении мыши, `:active` — во время активации, `:focus-visible` выделяет элемент, когда браузер считает нужным показать фокус, в частности при переходе клавишей Tab.

`::after` создаёт декоративный псевдоэлемент: так добавляется значок после внешних ссылок. `aria-label` даёт навигации понятное имя, `aria-labelledby` связывает раздел с его видимым заголовком.

Ссылка «Skip to content» позволяет пользователю клавиатуры сразу перейти к основному тексту.

## Что попробовать самостоятельно

1. Заменить `--accent` и посмотреть, какие элементы изменились.
2. Добавить один курс в список и один пункт меню.
3. Поменять пропорции сетки на `6fr 3fr 2fr` и объяснить результат.
4. Изменить порог 725 px на 700 px и проверить обе стороны границы в DevTools.
5. Убрать `flex-wrap: wrap` у меню и посмотреть, что происходит на телефоне.
6. Пройти по ссылкам клавишей Tab и найти правило, которое рисует рамку фокуса.

## Git

Git хранит версии файлов локально, GitHub размещает удалённый репозиторий. `git add` подготавливает изменения, `git commit` сохраняет версию, `git push` отправляет коммиты в удалённый репозиторий. `origin` — имя удалённого репозитория, `main` — имя основной ветки.

Перед защитой откройте HTML и CSS рядом с браузером и попробуйте внести изменения из списка выше без подсказки.
