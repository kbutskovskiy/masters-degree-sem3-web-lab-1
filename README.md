# Лабораторная работа № 1 — адаптивная страница

Учебное воспроизведение страницы **St Huxley's Community College** на HTML и CSS.

Образец: https://aabbphd.github.io/instituteWebClasses/mdn_adaptive/

## Как открыть

Откройте `index.html` двойным щелчком. Устанавливать зависимости или собирать проект не нужно. Шрифты и иконка находятся в проекте, поэтому оформление работает без интернета.

При желании можно запустить локальный сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Затем открыть http://localhost:8000. Остановка сервера — `Ctrl+C`.

## Файлы

- `index.html` — содержание и семантическая структура страницы.
- `styles.css` — шрифты, оформление и адаптивная сетка.
- `assets/fonts/` — локальные шрифты Lovato Light и Josefin Slab Bold из образца.
- `assets/external-link.svg` — самостоятельно нарисованная иконка внешней ссылки.
- `STUDY.md` — краткие пояснения к коду для подготовки к защите.
- `.nojekyll` — файл для публикации обычного статического сайта через GitHub Pages.

## Адаптивность

| Ширина окна | Расположение блоков |
| --- | --- |
| Более 950 px | Основной текст, курсы и меню в трёх колонках |
| 726–950 px | Курсы под текстом, меню справа |
| До 725 px | Меню под заголовком, далее текст и курсы в одну колонку |

На узких экранах пункты меню переносятся на следующие строки. В отличие от образца, нет фиксированной минимальной ширины 500 px: страница помещается и на телефоне шириной 320 px.

## Что сделано

Сохранены английское содержание, порядок разделов, цветовые акценты, шрифты, списки и общий вид образца. Разметка и стили написаны заново: для основных блоков используется CSS Grid, для меню — Flexbox. JavaScript для этой статической страницы не требуется.

Добавлены выделение ссылок при навигации клавиатурой и ссылка «Skip to content», появляющаяся при нажатии Tab. Ссылки Home, Courses и Prospectus ведут к соответствующим частям страницы. Внешние ссылки ведут в Wikipedia. Остальные ссылки с `href="#"` — учебные заглушки, как в образце: отдельных страниц, формы записи и сервера в задании нет.

## Публикация через GitHub Pages

После загрузки файлов в репозиторий откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните. GitHub покажет адрес опубликованного сайта. Для сдачи задания достаточно ссылки на сам репозиторий, если преподаватель не попросил ссылку на работающую страницу.

## Источники

Текст и внешний вид воспроизводят учебный образец преподавателя. Два файла шрифтов взяты из [каталога fonts исходного учебного проекта](https://github.com/aabbPhD/instituteWebClasses/tree/main/mdn_adaptive/fonts). HTML и CSS образца целиком не копировались.
